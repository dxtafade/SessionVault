# Картинки для Web Store — задача Люцику

Готовим публикацию **бесплатной** версии Session Vault в Chrome Web Store. С тебя —
картинки для листинга (магазина). Снимать с ветки **`release/free-no-sync`** (там
кнопка облака ☁ уже скрыта — это правильная версия для скринов): грузишь расширение
локально через `chrome://extensions` → «Load unpacked».

## Что нужно

**1) Скриншоты — 5 штук, 1280×800, PNG.** Главное, что увидят в магазине. Шот-лист с подписями:

1. **Стол с сессиями** (несколько стопок на полках) — подпись «All your tabs, tidied into sessions».
2. **Сохранение вкладок** (кнопка «＋ SAVE OPEN TABS» / появление новой сессии) — «One click to save everything».
3. **Deal-out / восстановление** (карточный разворот вкладок сессии с Restore all) — «Bring a whole session back instantly».
4. **Crash-recovery баннер** («Did your browser close unexpectedly?») — «Never lose your tabs to a crash».
5. **Двуязычность + тёмная тема** (переключатель EN/RU и/или dark theme) — «Light or dark · English / Русский».

**2) Small promo tile — 1 штука, 440×280, PNG** (желательно, показывается в сетках магазина).
Marquee 1400×560 — только если решим заявляться на фичеринг, пока не обязательно.

Иконка 128×128 уже есть (`icons/icon128.png`) — её не трогай.

## Стиль

Наш Flip Desk: фон-стол (`#E9E1D2` с зерном), щедрые отступы, подписи Archivo bold,
один горчичный акцент, текста по минимуму (чтобы читалось в превью). Скрины — реальные
из расширения. **Минимум один скриншот сделай на русском** (переключи язык кнопкой
EN/RU), чтобы показать двуязычность.

## Формат сдачи

5× 1280×800 PNG + 1× 440×280 PNG — кинь в папку `store/` в репо или как удобнее.
